# Simulation and Numerical Resolution of Fermi’s Equations for a Quantum Ideal Gas

**Numerical Resolution of Fermi’s Equations and Low-Temperature Simulations**

This repository contains the code and scripts for simulating a quantum ideal gas under Fermi–Dirac statistics. The project reproduces Fermi’s assumptions, performs numerical integration of his original theoretical equations, and illustrates the behavior of the system at low temperatures through Monte Carlo simulations based on [1].


## References

[1] Monte Carlo Simulation of an Ideal Quantum Gas. Clark University, 2009. Available at: [https://stp.clarku.edu/simulations/qmc/index.html](https://stp.clarku.edu/simulations/qmc/index.html). Accessed October 5, 2025.
